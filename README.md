# SAFE-Shop

SAFE-Shop è una piattaforma web che stima l’affidabilità dei siti e-commerce
per aiutare a individuare possibili truffe online.

L’applicazione analizza diversi indicatori, tra cui:
- indicatori tecnici
- reputazione online
- età del dominio
- recensioni degli utenti

Sulla base delle informazioni raccolte, il sistema calcola una percentuale
di affidabilità utilizzando un algoritmo a pesi ponderati e mostra
un report sintetico dei risultati.

Il progetto ha finalità informative e didattiche e fornisce una stima
indicativa basata su dati pubblicamente disponibili.


## Funzionalità

- Analisi tecnica del sito web
- Valutazione dell’età del dominio
- Analisi delle recensioni online
- Calcolo della percentuale di affidabilità
- Visualizzazione di un report riepilogativo


## Come funziona

1. L’utente inserisce l’URL di un sito e-commerce
2. SAFE-Shop raccoglie i dati necessari
3. I dati vengono elaborati tramite un algoritmo a pesi ponderati
4. Viene restituita una percentuale di affidabilità con un report sintetico


## Disclaimer

SAFE-Shop fornisce una valutazione indicativa.
I risultati non garantiscono l’assenza di truffe e non sostituiscono
verifiche professionali o il giudizio dell’utente.
